# 现金流量表主表工作底稿

在Windows中使用文件选择窗口准备运行：

```powershell
python scripts\engine_launcher.py prepare --select
```

查看状态或完成确认：

```powershell
python scripts\engine_launcher.py status --run-dir "运行目录"
python scripts\engine_launcher.py finalize --run-dir "运行目录" --decisions "确认结果.json"
```

固定输入为审定资产负债表、审定利润表、科目余额表、已拆好的一借一贷明细、上年度审定现金流量表和实际执行重要性水平。账表调整和审计调整可在选择窗口中按需提供。程序使用现成的借贷科目关系补充工作底稿事实，不重新配对分录，也不要求人工填写现金流标签；已有标签冲突会在底稿中列出。结果及内部追溯资料写入所选输出目录下的“现金流量表运行”。

输出Excel固定包含两张可见工作表：“现金流量表”和“计算验证底稿”。正表金额为冻结数值；验证底稿列示账表调整桥和孤立调整、未映射科目、判断证据、受限资金期初期末、账务核对明细、逐项目组成、来源、自动分类及调整处理，并以工作簿内部公式反算正表。上期数只从上年度审定现金流量表搬取，不复算上期组成；名称未匹配会明确提示。

支持一般企业、银行、证券、保险和其他金融企业。保险企业自动识别2018旧格式和2023新保险合同准则格式；金融企业发行债券收到的现金独立列示。
